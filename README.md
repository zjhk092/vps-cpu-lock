## 独享 CPU VPS 到底指什么：锁核 VDS 和“固定核心数”是两回事

真正的独享 CPU，指你的虚拟核心被固定绑在专属物理核心上，其他用户的虚拟机永远不会被调度进来，凌晨三点跑构建和下午三点一样快。

普通 VPS 的做法是把一台物理机的核心时间切片，分给几十个租户共用，邻居一忙你就得排队。这种差异平时不明显，一旦跑持续吃 CPU 的任务就藏不住了。很多共享方案还带“基准性能 + 积分爆发”机制（AWS 的 T 系列、DigitalOcean 的 Basic 都属于这类），积分耗尽后会掉回基准速度，持续满载的活儿根本撑不住。

选购时有个文字游戏要留意：商家写“1 dedicated vCPU”，可能指一个完整物理核心（含两个超线程），也可能只给你一个线程。只给线程的话，同一核心上的另一个线程照样能拖慢你。真锁核的商家会明确写 pinned cores，并且愿意给你完整核心。

到手之后有个简单的验证办法：跑 `top`，看 `%st`（steal time）。这个数字持续超过 5%，说明你一直在等别人用完核心，所谓“独享”名不副实；长期接近 0% 才算干净。

### 独享 CPU 一定比共享 CPU 好吗？

不一定，先看钱花在哪。同一台 64 核物理机，共享方案能塞几十个租户，独享只能塞十几个，成本摆在那里，独享价格翻倍是正常定价逻辑。日均核心利用率长期低于一半、负载间歇型的用途（博客、测试环境、静态站），共享方案便宜够用；数据库、游戏服务器、持续编译这类持续满载的任务，才值得为独享付几倍的钱。

### 怎么验证商家真给了独享核心？

下单前问三个问题：给的是完整物理核心还是单个线程？有没有核心绑定？有没有测试 IP 可以先测速。到手后看 `top` 里的 `%st`，持续高于 5% 就是有邻居在抢，趁退款期处理。
